# Search Messages

Semantic search over short-term memory messages.

## What it does

Performs semantic similarity search across your raw conversation messages (short-term memory). Useful for finding recent conversations, specific discussions, or earlier context that may not have been extracted into long-term memories yet.

Message search is transcript retrieval, not graph recall. It searches retained STM messages and returns the closest raw message/turn matches after channel/session filters. Use it when exact wording matters; use `crystal_recall` for distilled durable memory and `crystal_query_knowledge_base` for curated reference material.

## Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `query` | string | Yes | Search query (minimum 1 character) |
| `limit` | number | No | Maximum results to return (default: 10, max: 100) |
| `channel` | string | No | Filter by exact channel or peer scope (e.g., `peer-coach:511172388`). Omit only when broad account-level search is intended. Search is channel-isolated and never crosses clients. |
| `sessionKey` | string | No | Filter by exact session key for transcript-local lookup. |
| `sinceMs` | number | No | Lower time bound (Unix ms). Alias of `fromMs`. |
| `fromMs` | number | No | Lower time bound of the window (Unix ms). |
| `toMs` | number | No | Upper time bound of the window (Unix ms). |
| `startDate` | string | No | Lower time bound as an ISO date (e.g. `2026-06-01`). |
| `endDate` | string | No | Upper time bound as an ISO date (e.g. `2026-06-30`). |
| `offset` | number | No | Skip this many ranked results for pagination; walk the full set with `response.pagination.nextOffset`. |

## Returns

Returns formatted message results and JSON:

```
## Message Search Results
Query: "database migration"

1. [assistant] The migration to PostgreSQL requires... (score: 0.94)
   timestamp: 2026-04-16 14:30:00

2. [user] Should we run the migration on a Friday? (score: 0.89)
   timestamp: 2026-04-15 10:15:00
```

And structured JSON:
```json
{
  "query": "database migration",
  "results": [
    {
      "_id": "msg_123",
      "role": "assistant",
      "content": "The migration to PostgreSQL requires...",
      "channel": "slack",
      "timestamp": 1713284400000,
      "score": 0.94
    }
  ],
  "limit": 10,
  "channel": "slack"
}
```

## Examples

### Search recent conversations

```
crystal_search_messages(query="authentication bug fix")
```

Returns messages matching "authentication bug fix" from recent conversations.

### Search within a time window ("what did X say last month about Y")

```
crystal_search_messages(
  query="API redesign",
  channel="peer-coach:511172388",
  startDate="2026-06-01",
  endDate="2026-06-30",
  limit=50,
  offset=0
)
```

Searches for "API redesign" in that peer's June 2026 messages. Page the full set
with `offset` (`response.pagination.nextOffset`) while `pagination.hasMore` is
`true` — never conclude a window is empty from a single page.

### Search channel-specific messages

```
crystal_search_messages(
  query="Q2 roadmap",
  channel="slack",
  limit=10
)
```

Returns messages about "Q2 roadmap" from Slack channels only.

### Quick recent lookup

```
crystal_search_messages(query="Sarah", limit=3)
```

Finds the 3 most recent messages mentioning Sarah.

## When to use

- **Find recent context** — Quickly locate a conversation from earlier today or this week
- **Recall details** — Remember specifics from a discussion before it was extracted into memories
- **Search by channel** — Find messages from a specific source (Slack, Discord, email, etc.)
- **Search by session** — Confirm wording from a known session without pulling unrelated messages
- **Temporal search** — Search only recent messages or messages within a date range
- **Verify information** — Double-check details directly from conversation history

## Comparison to Other Tools

| Tool | Search Across | Best For |
|------|---|---|
| `crystal_search_messages` | Raw STM messages | Finding recent conversations verbatim |
| `crystal_recall` | Extracted memories (LTM) | Finding synthesized facts and decisions |
| `crystal_query_knowledge_base` | Imported KB chunks | Searching specific documents or channels |

## Errors

| Error | Cause | Resolution |
|-------|-------|-----------|
| `query is required` | No search query provided | Provide a search string (1+ characters) |
| `channel must be a string` | Invalid channel type | Pass a string like "slack" or "discord" |
| Embedding service unavailable | OpenAI embeddings down | Retry in a moment |

## Notes

- Searches are case-insensitive
- Results are ranked by semantic similarity score (0-1, higher = better match)
- Results are not graph-ranked and do not use KB `sourceRole`; apply `channel`/`sessionKey` when precision matters.
- Limit defaults to 10 if not provided or invalid; max 100
- Time bounds accept Unix ms (`fromMs`/`toMs`) or ISO dates (`startDate`/`endDate`); a plausible seconds value is auto-upscaled to ms
- `offset` pages the ranked, time-bounded set; the response echoes `pagination.hasMore`/`nextOffset` and the resolved `window`
- Requires an updated MCP server build to expose `fromMs`/`toMs`/`startDate`/`endDate`/`offset`; the underlying HTTP API accepts them immediately
- API-key clients embed server-side; JWT clients embed locally
- Message retention depends on your Memory Crystal tier (Free: 7 days, Pro: 30 days, Ultra: 90 days)
- Short-term messages are eventually archived; use `crystal_recall` for long-term facts
- If stale OpenClaw sensory residue appears in recall quality audits, use the admin stale sensory cleanup action rather than broad message deletion.
