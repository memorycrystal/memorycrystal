This page is for the fast answers.

## What this means in practice

### Does Memory Crystal support Claude Code?
Yes, at **Full** tier. Automatic capture and recall via Context Injection. See [Claude Code](/integrations/claude-code) and [Support Tiers](/concepts/support-tiers).

### Does Memory Crystal support Claude Desktop?
Claude Desktop is **Tools** tier, not an official platform. The installer still registers the Explicit Tool Surface via `--targets claude-desktop` or `--targets generic-mcp`. Capture and recall are deliberate tool calls. See [Claude Desktop](/integrations/claude-desktop) and [Support Tiers](/concepts/support-tiers).

### Does Memory Crystal support Codex CLI?
Yes, at **Full** tier. Codex Desktop shares that Full capability through `~/.codex` but is not an official platform. See [Codex CLI](/integrations/codex-cli) and [Support Tiers](/concepts/support-tiers).

### Does Memory Crystal support Factory Droid?
Factory Droid is **Tools** tier, not an official platform. `--targets factory-droid` still works, and so does `--targets generic-mcp`. Capture and recall are deliberate tool calls. See [Factory Droid](/integrations/factory-droid) and [Support Tiers](/concepts/support-tiers).

### Does Memory Crystal support Grok?
Yes, at **Capture tier**. The installer registers tools, automatic capture, skills, and a Managed Block in `~/.grok/AGENTS.md`. Recall is deliberate, not automatic: Grok ignores hook stdout on passive events, so the harness cannot inject context. Call `crystal_recall` or `crystal_what_do_i_know`. See [Grok Build](/integrations/grok).

### Does Memory Crystal install into Buzz?
No. Buzz is a **Hosted** platform. It runs other agents through buzz-acp. Install Memory Crystal into the CLI Buzz is running. Channel memory is not available, and channel isolation is not enforced. See [Buzz](/integrations/buzz).

### What is a Support Tier?
The portion of the Integration Contract a harness can actually honour. Badges are derived from the capability table. See [Support Tiers](/concepts/support-tiers).

## How it actually works

Support differs by integration path.
Some clients use the current Streamable HTTP MCP path, while some compatibility paths still rely on the deprecated package.
